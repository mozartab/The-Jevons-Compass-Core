# The Jevons Compass (TJC)
**Status:** Alpha Prototype (v0.1)
**Stack:** Python (Logic), React (Dashboard), JSON (Data Structure)

### The Problem
The **Jevons Paradox** states that as technology increases the efficiency with which a resource is used, the total consumption of that resource increases rather than decreases. In footwear manufacturing, AI-accelerated design is leading to a "Rebound Effect" of increased sample waste and persistent microplastic pollution.

### The Solution
The Jevons Compass is a supply chain audit tool designed to:
1.  **Quantify** the Rebound Effect in sampling pipelines.
2.  **Visualize** the "Red Zone" where efficiency creates liability.
3.  **Validate** material interventions (like Project LITHOS) to decouple growth from pollution.

### Core Modules
* `jevons_logic.py`: The backend algorithm for calculating waste-per-efficiency-unit.
* `material_audit.json`: The data structure for tracking material components (e.g., Olivine vs. Carbon Black).
* `CompassDashboard.jsx`: Frontend visualization logic for supply chain directors.
